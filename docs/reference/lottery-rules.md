# 7 大彩种开奖规则参考（开发权威基准）

> **用途**：领域层 `LotterySpec` / `prize_tables`、号码管理页玩法/称呼、奖级判定的**单一事实源**。  
> **来源**：中国福彩官网（cwl.gov.cn）、中国体彩官网（lottery.gov.cn）、中彩网权威转载规则全文，由子代理于 2026-06-19 按 spec 所需维度复核。  
> **⚠️ 规则会随政策调整**：实现时固定档奖金/比例应**可配置**，并在数据层标注规则版本与生效期。  

---

## 阅读说明

| 维度 | 含义 | 实现落点 |
|---|---|---|
| 号码规则 | 每注号码的取值范围、个数、是否分区 | `LotterySpec.front` / `LotterySpec.back` |
| 号码风格 | `partition`（分区组合）/ `positional`（按位数字） | `LotterySpec.number_style` + `CompareStrategy` 路由 |
| 玩法 | 官方支持的投注方式 | `tickets.play_type` 合法值 |
| 号码区称呼 | 官方对号码区的命名 | UI 文案、开奖结果渲染 |
| 倍投 | 倍数范围、单张金额上限 | `tickets.multiplier` + 校验 |
| 追加 | 仅大乐透独有的追加投注 | `tickets.append` + 奖金计算 |
| 奖级 | 命中条件、固定/浮动奖金 | `prize_tables` 配置 |
| 开奖日 | 每周开奖的具体日期 | `lottery_types.draw_schedule_json` |

## 1. 双色球 `ssq`

### 1.1 号码规则
- 红色球号码区：01–33，选 6 个
- 蓝色球号码区：01–16，选 1 个
- 每注金额：人民币 2 元

### 1.2 玩法
1. **单式投注**：6 红 + 1 蓝
2. **复式投注**
   - 红色球号码复式：红球选 7 个及以上，蓝球 1 个
   - 蓝色球号码复式：红球 6 个，蓝球选 2 个及以上
   - 全复式：红球选 7 个及以上，蓝球选 2 个及以上
3. **胆拖投注**
   - 单式胆拖：红球胆码 1–5 个 + 拖码（胆+拖≥7），蓝球 1 个
   - 复式胆拖：红球胆码 1–5 个 + 拖码（胆+拖≥7），蓝球 2 个及以上

### 1.3 倍投
- 倍数范围：2–99 倍
- 单张彩票投注金额最高不得超过 20,000 元

### 1.4 开奖日
每周二、周四、周日开奖（休市日除外）。

### 1.5 奖级表
| 奖级 | 命中条件 | 奖金类型 | 单注奖金（常规） |
|---|---|---|---|
| 一等奖 | 6 红 + 1 蓝 | float | 浮动，最高 500 万 |
| 二等奖 | 6 红 + 0 蓝 | float | 浮动，最高 500 万 |
| 三等奖 | 5 红 + 1 蓝 | fixed | 3,000 元 |
| 四等奖 | 5 红 + 0 蓝 或 4 红 + 1 蓝 | fixed | 200 元 |
| 五等奖 | 4 红 + 0 蓝 或 3 红 + 1 蓝 | fixed | 10 元 |
| 六等奖 | 2 红 + 1 蓝 或 1 红 + 1 蓝 或 0 红 + 1 蓝 | fixed | 5 元 |

> 当奖池资金≥15 亿元时执行特别规定：一等奖、二等奖奖金分配比例变化，并增设福运奖（任意 3 红，5 元）。MVP 暂按常规规则实现，特别规定可配置化预留。

## 2. 大乐透 `dlt`

### 2.1 号码规则
- 前区号码：01–35，选 5 个
- 后区号码：01–12，选 2 个
- 每注基本投注金额：人民币 2 元

### 2.2 玩法
1. **单式投注**：5 前区 + 2 后区
2. **复式投注**
   - 前区复式：前区 6 个及以上，后区 2 个
   - 后区复式：前区 5 个，后区 3 个及以上
   - 双区复式：前区 6 个及以上，后区 3 个及以上
3. **胆拖投注**
   - 前区胆拖：前区胆码 1–4 个 + 拖码（胆+拖≥6），后区 2 个
   - 后区胆拖：前区 5 个，后区胆码 1 个 + 拖码≥2 个
   - 双区胆拖：前区胆码 1–4 个 + 拖码（胆+拖≥6），后区胆码 1 个 + 拖码≥2 个
4. **追加投注**：基本投注基础上，每注追加 1 元；追加仅参与一、二等奖奖金分配

### 2.3 倍投
- 倍数范围：2–99 倍
- 单张彩票基本投注最大金额≤20,000 元
- 单张彩票基本+追加最大金额≤30,000 元

### 2.4 追加奖金
追加投注中得浮动奖时，追加单注奖金 = 当期基本投注对应单注奖金的 **80%**（2019 现行规则）。

### 2.5 开奖日
每周一、周三、周六开奖（休市日除外）。

### 2.6 奖级表（常规奖池 < 8 亿元）
| 奖级 | 命中条件 | 奖金类型 | 单注奖金 |
|---|---|---|---|
| 一等奖 | 5 前区 + 2 后区 | float | 浮动，最高 500 万 |
| 二等奖 | 5 前区 + 1 后区 | float | 浮动，最高 500 万 |
| 三等奖 | 5 前区 + 0 后区 或 4 前区 + 2 后区 | fixed | 5,000 元 |
| 四等奖 | 4 前区 + 1 后区 | fixed | 300 元 |
| 五等奖 | 4 前区 + 0 后区 或 3 前区 + 2 后区 | fixed | 150 元 |
| 六等奖 | 3 前区 + 1 后区 或 2 前区 + 2 后区 | fixed | 15 元 |
| 七等奖 | 3 前区 + 0 后区 或 2 前区 + 1 后区 或 1 前区 + 2 后区 或 0 前区 + 2 后区 | fixed | 5 元 |

> 当奖池≥8 亿元时，三–七等奖固定奖金提升（如三等奖 6,666 元），实现时应做成可配置。

## 3. 七乐彩 `qlc`

### 3.1 号码规则
- 基本号码：01–30 中选择 7 个
- 特别号码：从同一 01–30 池中摇出 1 个
- 每注金额：人民币 2 元

### 3.2 玩法
1. **单式投注**：从 30 个号码中选 7 个
2. **复式投注**：从 30 个号码中选 8–16 个
3. **胆拖投注**：选择 1–6 个胆码，再补充拖码，组成每 7 个号码一组的多注投注
4. **多倍投注**：2–99 倍

### 3.3 倍投
- 倍数范围：2–99 倍

### 3.4 开奖日
每周一、周三、周五开奖。

### 3.5 奖级表
| 奖级 | 命中条件 | 奖金类型 | 单注奖金 |
|---|---|---|---|
| 一等奖 | 7 个基本号码 | float | 高奖等 70%，最高 500 万 |
| 二等奖 | 6 个基本号码 + 特别号码 | float | 高奖等 10% |
| 三等奖 | 6 个基本号码 | float | 高奖等 20% |
| 四等奖 | 5 个基本号码 + 特别号码 | fixed | 200 元 |
| 五等奖 | 5 个基本号码 | fixed | 50 元 |
| 六等奖 | 4 个基本号码 + 特别号码 | fixed | 10 元 |
| 七等奖 | 4 个基本号码 | fixed | 5 元 |

> 高奖等（一、二、三等奖）按中奖注数均分当期高奖等奖金；低奖等（四–七等奖）为固定奖。

## 4. 七星彩 `qxc`

### 4.1 号码规则（⚠️ 2020-10-13 改版后现行规则）
- 前六位：从 000000–999999 中选取 1 个 6 位数字（每位 0–9）
- 最后一位：从 0–14 中选取 1 个数字
- 共同组成一注号码
- 每注金额：人民币 2 元

### 4.2 玩法
1. **单式投注**：前六位 1 个 6 位数字 + 最后一位 1 个数字
2. **复式投注**
   - 前六位复式：前六位中 1 位或多位选 2 个及以上数字，最后一位 1 个
   - 最后一位复式：前六位 1 个 6 位数字，最后一位选 2 个及以上数字
   - 全复式：前六位 1 位或多位选 2 个及以上数字，最后一位选 2 个及以上数字

### 4.3 倍投
- 倍数范围：2–99 倍
- 单张彩票投注金额最高不得超过 20,000 元

### 4.4 开奖日
每周二、周五、周日开奖。

### 4.5 奖级表
| 奖级 | 命中条件 | 奖金类型 | 单注奖金 |
|---|---|---|---|
| 一等奖 | 全部 7 位数字与开奖号码对应位置相同 | float | 浮动，最高 500 万 |
| 二等奖 | 前 6 位数字与开奖号码对应位置相同 | float | 浮动，最高 500 万 |
| 三等奖 | 前 6 位中任意 5 位对应位置相同，且最后一位相同 | fixed | 3,000 元 |
| 四等奖 | 任意 5 位数字与开奖号码对应位置相同 | fixed | 500 元 |
| 五等奖 | 任意 4 位数字与开奖号码对应位置相同 | fixed | 30 元 |
| 六等奖 | 任意 3 位对应位置相同；或前 6 位中任意 1 位相同且最后一位相同；或仅最后一位相同 | fixed | 5 元 |

> 当奖池≥3 亿元时，一、二等奖奖金分配比例倒置（一等奖 10%，二等奖 90%）。

## 5. 福彩3D `fc3d`

### 5.1 号码规则
- 投注号码由 000–999 组成
- 三个位置从左至右分别为「百位」「十位」「个位」
- 一组三个号码的排列或组合称为一注
- 每注金额：人民币 2 元

### 5.2 玩法（官方现行 15 种）
| 玩法 | 说明 | 单注奖金 |
|---|---|---|
| 单选 | 对三个号码以唯一排列方式投注 | 1,040 元 |
| 组选3 | 三个号码中有两个相同，覆盖 3 种排列 | 346 元 |
| 组选6 | 三个号码各不相同，覆盖 6 种排列 | 173 元 |
| 1D | 对百位、十位或个位中某一特定位置投注 | 10 元 |
| 猜1D | 对百位、十位或个位中任意一个位置投注 | 猜中1: 2 元；猜中2: 12 元；猜中3: 230 元 |
| 2D | 对百位和十位、十位和个位或百位和个位，以唯一排列投注 | 104 元 |
| 猜2D | 对任意两个位置投注 | 两同号: 37 元；两不同号: 19 元 |
| 通选 | 对三个号码以唯一排列方式投注 | 通选1: 470 元；通选2: 21 元 |
| 和数 | 对三个号码相加之和投注 | 按和数 0–27 分档，14–1,040 元不等 |
| 包选3 | 同时用单选和组选3投注 | 全中: 693 元；组中: 173 元 |
| 包选6 | 同时用单选和组选6投注 | 全中: 606 元；组中: 86 元 |
| 猜大小 | 对三个号码相加之和的大（19–27）小（0–8）投注 | 6 元 |
| 猜三同 | 对全部三个相同号码投注 | 104 元 |
| 拖拉机 | 对升序或降序连续排列的号码投注（890、098、901、109 除外） | 65 元 |
| 猜奇偶 | 对全部三个号码的奇偶性质投注 | 8 元 |

### 5.3 倍投
- 倍数范围：2–99 倍
- 单张彩票投注金额最高不得超过 20,000 元

### 5.4 开奖日
每天开奖一次。

### 5.5 中奖条件要点
- **单选**：投注号码与开奖号码按位全部相同
- **组选3**：开奖号码任意两位相同，投注号码数字相同（顺序不限）
- **组选6**：开奖号码三位各不相同，投注号码数字相同（顺序不限）

## 6. 排列3 `pl3`

### 6.1 号码规则
- 从 000–999 中选取 1 个 3 位数作为一注投注号码
- 三个位置为「百位」「十位」「个位」
- 每注金额：人民币 2 元

### 6.2 玩法
1. **直选投注**：所选 3 位数以唯一排列方式作为一注
2. **组选投注**
   - 组选6：3 位数字各不相同，覆盖 6 种排列
   - 组选3：3 位数字中有 2 位相同，覆盖 3 种排列

### 6.3 倍投
- 倍数范围：2–99 倍
- 单张彩票投注金额最高不得超过 20,000 元

### 6.4 开奖日
每天开奖一次。开奖号码为排列5当期开奖号码的前三位。

### 6.5 奖级表
| 玩法 | 命中条件 | 单注奖金 |
|---|---|---|
| 直选 | 数字相同且顺序一致 | 1,040 元 |
| 组选3 | 数字相同，顺序不限，开奖号码有 2 位相同 | 346 元 |
| 组选6 | 数字相同，顺序不限，开奖号码三位各不相同 | 173 元 |

## 7. 排列5 `pl5`

### 7.1 号码规则
- 从 00000–99999 中选取 1 个 5 位数为投注号码
- 五个位置为「万位」「千位」「百位」「十位」「个位」
- 每注金额：人民币 2 元

### 7.2 玩法
- **直选单式**：所选 5 位数字与开奖号码全部相同且顺序一致

### 7.4 开奖日
每天开奖一次。

### 7.5 奖级表
| 奖级 | 命中条件 | 单注奖金 |
|---|---|---|

## 8. 通用规则

### 8.1 兑奖期限
所有彩种统一为自开奖之日起 **60 个自然日**内兑奖，逾期未兑视为弃奖，弃奖奖金纳入彩票公益金。

### 8.2 税务提示
单注彩票中奖金额超过 **10,000 元**（含）者，须缴纳 **20%** 个人所得税，由兑奖机构代扣代缴。

### 8.3 金额存储约定
系统内部金额统一以「分」为单位（`int`），展示层除 100 显示为元，避免浮点误差。

### 8.4 不可兼中兼得
当期每注投注号码只兑付所中得的最高奖级奖金，不能兼中兼得（另行设立的特别奖除外）。

## 9. 给实现的建议

1. **号码区建模**：双色球/大乐透/七乐彩/七星彩 = 多区结构（`partition`）；福彩3D/排列3/排列5 = 按位结构（`positional`）。七星彩为混合型 `partition`：前区按位 6 位 + 后区单值 0–14。
2. **玩法不要硬编码「单式/复式/胆拖」三件套**：
   - 分区型彩种：单式、复式、胆拖
   - 福彩3D：13 种独立投注方式
   - 排列3：直选、组选3、组选6
   - 排列5：直选单式
3. **倍投**：统一 2–99 倍，单张上限按彩种配置（默认 20,000 元；大乐透基本+追加 30,000 元）。
4. **追加**：仅大乐透，独立标志位 `append`，追加奖金比例默认 80%（2019 现行规则），建议可配置。
5. **七星彩务必使用 2020 版规则**，数据层标注规则版本/生效期，避免与历史开奖冲突。
6. **奖级判定**：固定档奖金全部走配置表；浮动奖返回 `amount_type="float"`，展示「待官方派奖」。

## 10. 本仓库历史错误修正（对照 spec §5.1 / Plan 1 / prototype）

| 彩种 | 原错误 | 正确值 |

| 全部 | 倍投机制未建模 | 补倍投 2–99 倍 + 单张上限 |
